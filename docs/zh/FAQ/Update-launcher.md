# 问题

启动器无法更新或显示空白屏幕？这个快速指南解释了如何手动更新启动器。

!!! 注意

```
请确保您已通过官网（https://beammp.com）提供的安装程序完成BeamMP的安装及运行，然后再继续后续操作。
```

# 下载并安装一个新的启动器

1. 直接从[GitHub](https://github.com/BeamMP/BeamMP-Launcher/releases/latest/download/BeamMP-Launcher.exe)下载最新启动器。
2. 前往 BeamMP-Launcher.exe 所在目录。默认情况下，该文件夹位于 `C:\Users<username>\AppData\Roaming` 。将 <username> 替换为您的 Windows 用户名。如果您将 BeamMP 安装到了其他位置，例如 <code>D:\BeamMP-Launcher</code>，则请将启动器放入对应的 BeamMP-Launcher 文件夹中。</username>
3. 如适用时，请用新的启动器替换 BeamMP-Launcher 文件夹中现有的启动器。
4. 像往常一样启动 BeamMP-Launcher，查看是否正常运行。
